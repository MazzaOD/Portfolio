# Portfolio Website

A static HTML/CSS portfolio website that works without npm or build tools.

## Open the site

1. Open `index.html` directly in your browser.
2. Or use VS Code Live Server if you have it installed.

## Customize

- Edit `index.html` to update the content, headings, and links.
- Edit `styles.css` to update colors, spacing, and typography.

## Notes

- No `npm install` is required.
- This project is ready to host as a static site on GitHub Pages or any file server.
